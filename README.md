# EEMC — تحلیلگر سهام بورس ایران (Expo)

اپلیکیشن اندروید آماده ساخت با Expo.

## ساخت سریع APK (رایگان با حساب Expo)

### پیش‌نیازها
- نصب Node.js (نسخه LTS)
- یک حساب رایگان در [expo.dev](https://expo.dev)

### مراحل ساخت APK

در پوشه پروژه این دستورات را به ترتیب اجرا کنید:

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. نصب ابزار ساخت EAS
npm install -g eas-cli

# ۳. ورود به حساب Expo (مرورگر باز می‌شود)
eas login

# ۴. پیکربندی پروژه (فقط اولین بار)
eas build:configure

# ۵. ساخت APK
eas build --platform android --profile preview
```

بعد از چند دقیقه، لینک دانلود APK در ترمینال نمایش داده می‌شود.  
می‌توانید آن را روی گوشی اندروید خود نصب کنید (ممکن است نیاز به فعال کردن «منابع ناشناخته» باشد).

### نکات مهم
- این اپ فقط آموزشی است و توصیه سرمایه‌گذاری نیست.
- داده از سایت tsetmc.com دریافت می‌شود و نیاز به اینترنت دارد.
